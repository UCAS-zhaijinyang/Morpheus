This section is a result-writing template for the protocol in `usenix_security_2027_evaluation.txt`. Numeric cells remain placeholders until the frozen generation and detector runs finish. 6.1 Dataset construction and integrity

Morpheus-Harness uses deepseek-v4.1-flash across three organization scenarios. Each scenario contains 100 employees, 50 working days, 5,000 employee-days, 4,000 benign employee-days, and 1,000 insider-threat employee-days. The total Morpheus release contains 15,000 employee-days. One shared Enterprise Agent and one Personal Agent per employee are configured for every scenario.

ChimeraLog contains 5,000 records generated with deepseek-v4.1-flash in the internet-company scenario. CERT, TWOS, and UNM each contribute a fixed 5,000-record slice. TWOS, UNM, and ChimeraLog are used for realism. CERT is included in both realism and ITD.
