Morpheus · ICML 2027 research road

Morpheus-Harness：面向组织行为模拟的层级、人–Agent 协作与技能记忆 Harness

核心假设：真实的员工行为不是“每个人收到一份计划后独立调用工具”，而是由组织层级传递的目标、当前意图、会话状态、人–Agent 交接和可复用流程共同生成。Harness 负责控制这些中间变量，并把它们变成可审计的行为轨迹。

审稿判断：ICML 2027 中稿不能由“把四个模块拼起来”自动推出。ICML 2026 指南显示这些单点方向都已有中稿工作；本项目必须把贡献收敛为“组织级行为生成 Harness + 轨迹评测 + 安全审计协议”，并用消融实验证明每一层改变了数据真实性或安全性。下面的 已实现 代表仓库中已有代码，待验证 代表论文必须补做的实验。

OrgPlan

部门负责人先形成目标、依赖和容量约束，再由部门会议将其展开为员工级周目标；保留信息边界和组织依赖。

Research road：文献如何改变方案

T0

已有 Morpheus：全员计划 + 两 Agent 执行

仓库原始链路是全员 Workforce 会议、统一周目标、个人日计划，再由员工执行器按事件调用工具。优点是已有真实的日志和攻击注入路径；限制是组织信息流、路由策略和流程记忆没有被显式建模。

基线 论文问题被定义为“怎样让行为更真实”，而不是“怎样再增加一个 Agent”。

T1

从 TIPEX / Multi² / MAS-Orchestra 收敛出“编排是方法”

A Two-Tier Perspective on Inference-Time Parallelism 说明任务层与结构层编排应被统一控制；Multi² 说明层级分工可以降低长期交互中的目标漂移；MAS-Orchestra 强调 MAS 效果依赖任务结构、验证协议和调度器。

方向更新 把“部门负责人 → 部门 → 个人”定义为组织层的结构化编排，并把部门依赖写进中间产物。

T2

从 AgentXRay / GraphFlow / MAS-ProVe 加入可解释工作流

AgentXRay 将黑箱 Agent 近似为可解释工作流；GraphFlow 用图表示操作单元和工作流状态；MAS-ProVe 警告多智能体过程验证有高方差和上下文成本。

方向更新 不把最终答案当作唯一产物，新增层级会议 minutes、行为路由 CSV、human–agent handoff 事件和技能文件，供轨迹级评测与复现使用。

T3

从 Agentic Proposing / Meta Context / ProcMEM / COMAD 约束“skill”定义

Agentic Proposing 关注组合式技能合成；Meta Context Engineering via Agentic Skill Evolution 关注技能与上下文的协同进化；ProcMEM 将技能写成触发、执行和结束条件；COMAD 关注协作技能分区与复用。

方向更新 SkillMemory 只存前置条件、步骤摘要、工具画像和来源事件，按员工隔离并原子写入，避免把不透明的全文记忆冒充为程序化技能。

T4

从 Architecture Matters / AgentLAB / CausalTrace / ToolShield 引入安全闭环

Architecture Matters for Multi-Agent Security 指出角色分配、交互拓扑和记忆机制共同决定攻击面；AgentLAB 将长时攻击作为独立评测问题；Causal Detection of Multi-Step LLM Agent Attacks 关注顺序结构和反事实因果；ToolShield 说明多轮工具风险需要经验驱动的防御。

待验证 需要在论文实验中证明：层级信息流、技能复用和路由决策能产生不同的攻击面与可解释安全信号，而不是只增加日志数量。

TIPEX · Multi²分离高层目标与低层动作，控制长期漂移。已实现 head council 与 department meeting 两级；human-planner 与 tool-agent 两级。需要跨周目标一致性和依赖满足率实验。
AgentXRay · GraphFlow工作流应可重构、可解释、可管理。已实现 保存 hierarchy、minutes、behavior_policy 和 handoff 轨迹。需要工作流相似度、轨迹压缩率和复现性指标。
ProcMEM · Meta Context技能应包含触发、执行、复用和适配，而非只做文本检索。原型已实现 SkillMemory 提供 trigger terms、precondition、steps、tool profile 和 uses。需要成功率门控、技能污染实验和跨员工迁移实验。
Architecture Matters角色、拓扑、记忆是 MAS 攻击面。机制已暴露 层级和记忆均成为显式可替换模块。需要证明不同架构产生可区分的安全/效用曲线。
CausalTrace · CausalArmor多步攻击要分析信息影响的顺序与因果来源。设计阶段 先保留 stage、decision、skill provenance 等事件字段，为后续因果分析提供观测。尚未实现因果检测器；论文需加入反事实重放或因果归因实验。
AgentLAB · ToolShield单轮安全指标不足，需要长时、多轮、工具级评测。实验阶段 现有攻击场景可作为标注轨迹来源，新增路由和 skill 事件可用于切片。需构建安全基准协议、攻击预算、漏报/误报和效用指标。
AgentNoiseBench · Vulnerable Agent Identification工具反馈噪声和易损 Agent 会改变群体轨迹。实验阶段 IntentGate 为插入工具噪声与成员失效提供了单独的路由观测点。需做噪声强度、成员失效和恢复能力的系统扫描。

论文应检验的科学命题

Fidelity = f(organizational dependency, temporal consistency, interaction realism, skill reuse)
Safety = g(attack success, detection delay, false refusal, trace provenance)

Q1 · 组织真实性

层级规划是否提高跨部门依赖满足率、日程冲突可解释性、角色–任务一致性和行为转移的长尾结构？

基线：全员会议、随机部门、无依赖个人计划。

Q2 · Harness 效率

IntentGate 是否减少简单事件的模型调用和延迟，同时保持复杂任务的完成率与轨迹质量？

指标：LLM calls、token、latency、task success、route accuracy。

Q3 · 安全与复用

SkillMemory 是否提高重复流程的稳定性，又是否扩大了记忆投毒或权限漂移的攻击面？

必须同时报告复用收益、污染敏感性和来源可追溯率。

必须完成的实验包

消融

Global meeting / Hierarchical planning；always-agent / IntentGate；no skill / SkillMemory；single-agent / human–agent handoff。

真实性评测

时间间隔与 burstiness、跨成员通信图、计划–执行偏差、角色–工具互信息、跨日记忆一致性、下游 insider-threat detector 的 train/test 效果。

安全评测

离线 sandbox、合成身份、工具 allowlist、attack budget、长时攻击、间接注入、记忆污染、良性任务误拒绝；所有结果保留 provenance。
